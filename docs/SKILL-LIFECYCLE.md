# Skill ownership and lifecycle

This file is the public approval record for released skills.

## Ownership

- Owning team: Lattice Marketing
- GitHub maintainer: [@thomasboscatlattice](https://github.com/thomasboscatlattice)
- Backup owner: [@km-bunge](https://github.com/km-bunge)

The standard review cadence is every six months. A skill expires after twelve
months unless it is reviewed and given new dates. An expired skill must be
withdrawn from the Lattice Skills Library and must not be presented as current
until review is complete.

Review a skill sooner when its MCP tools, permissions, data handling, applicable
policy, or product workflow materially changes. Changes involving MCP access,
employee data, writes, or employment-related outputs require Security, Privacy,
Legal, and People review.

## Deprecation and withdrawal

The owning team may withdraw a skill immediately when it is unsafe, outdated,
or unsupported. Remove it from the Lattice Skills Library, mark the repository
copy as deprecated, and publish a short migration or removal note when one is
available. Do not silently replace a released skill with materially different
behavior.
