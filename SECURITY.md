# Security

Skills can contain instructions and executable scripts. Review every file and
use only AI tools approved by your organization.

## Reporting a vulnerability

Report suspected vulnerabilities privately through the
[Lattice Trust Center](https://trustcenter.lattice.com/). Do not disclose a
suspected vulnerability, exposed credential, or sensitive employee data in a
public GitHub issue.

Include the affected skill, reproduction steps, potential impact, and any known
mitigation.

If a credential or client secret may have been exposed, revoke or rotate it
immediately using your organization's approved process.

## Supported content

Only the current skills published by Lattice from this repository are reviewed
by Lattice. Modified copies and forks are not reviewed, supported, or endorsed
by Lattice.

See [Lattice MCP security and permissions](https://help.lattice.com/en-us/articles/15878584-lattice-mcp-security-and-permissions)
for authentication, permissions, sensitive-data, and credential guidance.
